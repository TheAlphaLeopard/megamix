# Sonic Megamix Mania in the browser

Browser port of Sonic Megamix Mania, based on the web port by [KBH Games](https://kbhgames.com/).

## Play

Open the [GitHub Pages site](https://thealphaleopard.github.io/megamix/) or open the [SVG launcher on jsDelivr](https://cdn.jsdelivr.net/gh/TheAlphaLeopard/megamix/loader.svg) directly in a browser tab.. The first load downloads approximately 236 MiB of game data; a modern browser with WebAssembly and WebGL is required. Click or tap the game to enable audio. Use the arrow keys to move, **A** to confirm or jump, **S** to go back, and **Enter** to pause. Touch controls are shown on touch devices; their separate **START** button pauses the game. Saves are periodically stored in the browser's IndexedDB, so clearing site data also clears the saves. Saves on GitHub Pages and jsDelivr are separate because they have different origins.
